## Files created

### `services/auth/src/main/java/com/themistra/auth/apikey/ApiKey.java`
Maps every `api_keys` column (V1) exactly as planned:
- `id` — identity PK.
- `keyUuid` — `UUID`, not null, `unique = true`, `updatable = false`, generated by the factory (`UUID.randomUUID()`), not caller-supplied.
- `accountId` — plain `Long` column, not null, `updatable = false`. No `@ManyToOne` to `Account` (L12).
- `prefix` — `String`, not null, `length = 16`, `updatable = false`. Maps `VARCHAR(16)` as-is; no attempt to widen it or otherwise resolve the L7-vs-column-width conflict, which the frozen brief explicitly defers to T24.
- `keyHash` — `String`, not null, `unique = true`, `updatable = false`, `@JdbcTypeCode(SqlTypes.CHAR)` + `columnDefinition = "char(64)"`, mirroring `RecoveryCode.codeHash` exactly (Phase 3 finding #2).
- `name` — `String`, not null, mutable (no mutator provided yet — T23 has nothing that renames a key).
- `scopes` — `List<String>`, not null, mutable, `@JdbcTypeCode(SqlTypes.ARRAY)` (Phase 3 finding #3). Compiles and passes `mvn -pl services/auth -am compile` cleanly against Hibernate 6.6.22's native Postgres array support — no custom converter needed.
- `lastUsedAt` / `expiresAt` / `revokedAt` — nullable `Instant`, mutable, no mutators provided (deferred to T24/T26 per the frozen brief).
- `createdAt` — not null, `updatable = false`, always caller-supplied; the DB's `DEFAULT now()` is never relied upon (Phase 3 finding #9).

Static factory `create(Long accountId, String prefix, String keyHash, String name, List<String> scopes, Instant createdAt)`: `Objects.requireNonNull` on every argument except `scopes`, which defaults to a fresh, defensively-copied `ArrayList` when null or non-null alike (matching `MfaEnrollment.create`'s defensive-copy convention for mutable arguments). Protected no-arg constructor for JPA only.

### `services/auth/src/main/java/com/themistra/auth/apikey/ApiKeyRepository.java`
Package-private interface extending `JpaRepository<ApiKey, Long>`, one method: `List<ApiKey> findByPrefix(String prefix)` — `List`, not `Optional`, per the frozen brief's resolution of Phase 3 finding #4 (`prefix` has no DB-level `UNIQUE` constraint).
