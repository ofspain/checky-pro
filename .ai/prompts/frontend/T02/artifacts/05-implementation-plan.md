## Risk noted for Phase 6
`shellBuildsAndMounts` mounts through `mountShell`, which now creates a browser router. jsdom's default URL is
`http://localhost:3000/`, which is outside `/app`. From the probe, the router then renders nothing and logs one
"does not start with the basename" warning. So:
- the `innerHTML === ''` assertion should still hold;
- the no-fetch, no-storage and no-worker assertions should hold too, because the router makes no requests.

Phase 6 confirms this. If the warning is the only effect, it is accepted as harmless test noise, because the frozen brief
forbids changing that test.
