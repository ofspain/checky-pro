## Public functions / components (signatures)
- `export function AppShell(): JSX.Element`: renders `<div data-testid="app-shell" />`. No props, no text, no effects.
- `export function mountShell(container: HTMLElement | null): Root`:
  - throws `Error('mountShell: root element #root not found')` if `container` is null;
  - otherwise `createRoot(container)`, `root.render(<StrictMode><AppShell /></StrictMode>)`, and returns the `Root` (so a
    test can `unmount()`).
- `main.tsx`: `mountShell(document.getElementById('root'));`. It has no exports.

## Tests (Phase 10, per the frozen Required Tests)
`shellBuildsAndMounts.test.tsx`, `describe('shellBuildsAndMounts')`:
1. `build()` from `vite` with `{ root: frontendDir, logLevel: 'silent', build: { outDir: <mkdtemp>, emptyOutDir: true } }`:
   - resolves;
   - `index.html` contains `src="/app/assets/`.
2. Mount into a fresh `div`: the `[data-testid="app-shell"]` element exists and its `textContent === ''`.
3. Negatives:
   - `vi.spyOn(globalThis, 'fetch')`;
   - spies on `Storage.prototype.setItem`;
   - a stub `navigator.serviceWorker.register`;
   - mount, then expect none called;
   - read every file under `src/` and assert none contains `import.meta.env`.
4. `expect(() => mountShell(null)).toThrow()`.

Per case, `act()` from `react` wraps the render so React 19 flushes synchronously.

## Execution order
1. Root `package.json`.
2. `frontend/package.json`, `tsconfig.json`, `vite.config.ts`, `index.html`.
3. `pnpm install` in a throwaway `node:22-alpine` container, mounting the repo (`corepack enable`). This produces
   `pnpm-lock.yaml`. The `node_modules` it creates on the host are ignored by `.gitignore`, and they are removed afterwards
   so they don't shadow the compose volumes.
4. `src/app/AppShell.tsx`, `src/app/mountShell.tsx`, `src/main.tsx`.
5. `pnpm -C frontend build` and `typecheck` in the container (AC1).
6. Live check (AC5):
   - `infra/local/bin/up --frontend`;
   - `curl http://localhost:5173/app/` and its module script through the edge;
   - an edit to observe hot reload.
7. CI job and README.
8. Phase 10: the test and the mutation breaks.
