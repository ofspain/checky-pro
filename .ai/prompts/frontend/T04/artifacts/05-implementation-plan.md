## Config shape (`frontend/.oxlintrc.json`)
- `$schema`: `./node_modules/oxlint/configuration_schema.json`. It is shipped in the package, so editors validate locally
  with no network. This is kept only if the file exists in 1.87.0; otherwise it is omitted.
- `categories`: `correctness`, `suspicious`, `pedantic`, `perf`, `style`, `restriction` and `nursery`, all `off`.
- `rules`:
  - `no-restricted-globals`: `["error", {name:"fetch",message}, {name:"XMLHttpRequest",message}]`.
  - `no-restricted-properties`: `["error", ...["window","globalThis","self","top","parent","opener","frames"].map(o =>
    ({object:o, property:"fetch", message}))]`.
- `message` everywhere is `"Call the backend through @themistra/api-client (L6)."`.
- No `overrides`, `plugins` or `ignorePatterns`.

If oxlint's default plugins add rules even with every category off, the phase 6 probe will show it ("with N rules"
must say 2) and `plugins: []` is set. That is still within "only the L6 rules".

## Private helpers (test file only)
- `const frontendDir`: from `expect.getState().testPath`, three `dirname`s up. This is the T03 pattern, because jsdom
  gives `import.meta.url` a non-file URL.
- `const configPath = join(frontendDir, '.oxlintrc.json')`.
- `const oxlintBin = join(frontendDir, 'node_modules/.bin/oxlint')`.
- `async function lint(target: string): Promise<{ code: number; output: string }>`:
  - `execFile(oxlintBin, ['-c', configPath, target])`;
  - it resolves on exit 0 and catches a rejection to read `code`, `stdout` and `stderr`;
  - it never throws on exit 1.
- `async function lintSource(name: string, source: string)`: writes `source` to `<tmp>/<name>.ts` and calls `lint` on
  that file.
- `const BANNED: ReadonlyArray<{ form: string; source: string; rule: 'no-restricted-globals' |
  'no-restricted-properties' }>`, with the 17 AC1 forms. The rule ids come from the phase 4 probe:
  - globals: bare `fetch()`, `const f = fetch`, `new XMLHttpRequest()`;
  - properties: the seven `<obj>.fetch` forms, the three bracket forms, `bind`, `call`, and `const { fetch } = window`.

  Phase 6 re-checks each id against the real output before the table is fixed.
- `const ALLOWED`, with the four AC3 sources:
  - a parameter named `fetch`;
  - a `const fetch`;
  - `createAuthClient().GET('/accounts/me')` with its import;
  - `vi.spyOn(globalThis, 'fetch')`.

The temp dir is created in `beforeAll` with `mkdtemp(join(tmpdir(), 'lint-l6-'))` and removed in `afterAll`.

## Tests (one file, five cases, following frozen-brief Required tests 1–5)
1. **AC1:** `it.each(BANNED)`, one result per form. Each expects `code === 1`, output containing the expected rule id,
   and the L6 message.
2. **AC3:** `it.each(ALLOWED)`. Each expects `code === 0`.
3. **AC4:** `lint(join(frontendDir, 'src'))` gives `code === 0`.
4. **AC2:** read `package.json`. Expect:
   - `scripts.lint === 'oxlint -c .oxlintrc.json src'`;
   - `scripts.build` to start with `'pnpm run lint && '`, with `tsc --noEmit` and `vite build` after it;
   - `devDependencies.oxlint === '1.87.0'`.
5. **AC5:** parse `.oxlintrc.json`. Expect:
   - no `overrides` key;
   - both rules' first element to be `'error'`;
   - the global names to be exactly `['fetch','XMLHttpRequest']`;
   - the property objects, sorted, to be exactly the seven names, each with `property: 'fetch'`.

Case 1 lints each fixture in its own oxlint run, so an exit code belongs to exactly one form. oxlint takes about 0.3 s per
run, so 21 runs are well under the default timeout. A 30 s timeout is set per case for a cold container.

**Manual check in phase 6 (not a committed test):** add a temporary violation file under `src` (backed up and then
removed), and confirm `pnpm -C frontend build` exits non-zero with no `tsc` or Vite output. That shows AC2 end to end.

## Execution order
1. `package.json`: add the devDependency and scripts; run `pnpm install` in the frontend container; restart the
   container (a dependency change).
2. `.oxlintrc.json`.
3. Probe: `pnpm -C frontend lint` exits 0 with "2 rules" on the real `src`, and the rule id is checked for each form.
4. The test file.
5. Run the full suite, then `pnpm -C frontend build`.
6. Mutation breaks: rule removed, `window` dropped, `top` dropped, lint removed from `build`, an `src` override. Each
   uses a backup and is restored, never `git checkout`.
7. The manual AC2 check.
